# Lampa Yani — документация

Новое расширение для Lampa на базе официального YummyAnime (Yani) API.

## Возможности MVP

- каталог аниме;
- каталог по жанрам;
- поиск по названию;
- расписание онгоингов;
- рейтинг Yani и раздел лучших аниме;
- вход в аккаунт Yani;
- оценка аниме от 1 до 10;
- избранное и пользовательские списки;
- отдельный раздел «Мои списки» с рядами последних добавленных тайтлов для авторизованного пользователя;
- просмотр комментариев;
- выбор озвучки и серии с воспроизведением прямого потока во внутреннем или внешнем плеере;
- блокировка Alloha в медиаплеерах без прямого потока с понятным предупреждением о Lampac;
- необязательное подключение собственного Lampac-сервера для преобразования Alloha в прямой HLS;
- собственный сервис-резолвер из папки `server/`, отдающий Alloha обычным HLS-потоком;
- пропуск опенингов и эндингов по таймингам AniSkip во внутреннем плеере;
- автопереход к следующей серии с заблаговременным получением её потока;
- отключаемая интеграция с приложением YummyTV;
- кнопка YummyAnime в стандартной карточке Lampa и регистрация в Online, если этот модуль доступен;
- отображение всех плееров и озвучек, возвращённых YummyAnime API;
- настройка предпочтительного плеера с запоминанием последнего источника;
- локальная история, продолжение последней серии, длительность и число просмотров;
- отключаемая автосинхронизация прогресса внутреннего плеера для авторизованных пользователей и ручная синхронизация на странице аккаунта;
- стандартные карточки Lampa для найденных позиций каталога и расписания YummyAnime;
- каталог «Продолжить просмотр» из локальной истории;
- действия YummyAnime и корректное чтение комментариев в стандартной карточке Lampa;
- постраничные комментарии и вложенные ветки ответов только для чтения;
- экран состояния YummyAnime с доступностью, задержкой и историей сервисов;
- переключение интерфейса расширения между русским, английским и украинским языками;
- компактный блок «Доступные переводы» на карточке тайтла: отдельные списки команд озвучки и субтитров без названий плееров и повторов;
- постеры, названия, год, рейтинг и описание;
- логотипы рейтинговых сервисов на карточках и в подробностях;
- альтернативные источники постеров: Jikan, Shikimori и AniList;
- переход к поиску выбранного аниме в Lampa;
- модульная структура для дальнейшего развития.

## Установка

1. Подключите URL файла `index.js` в разделе расширений Lampa.
2. По умолчанию расширение использует встроенный публичный ключ приложения YummyAnime for Lampa.
3. При необходимости откройте `Настройки → YummyAnime → Публичный ключ приложения` и укажите другой публичный ключ. Пустое значение возвращает стандартный ключ. Никогда не вводите здесь приватный ключ приложения.

Для установки используйте собранный файл с GitHub Pages. Есть две ссылки:

Продакшн — проверенный релиз. Ссылка не меняется; при серьёзном баге продакшн откатывается на предыдущий git-тег.

`https://yummyanime.github.io/yummy-lampa-plugin/stable/index.js`

Тестовая — последняя сборка ветки `main`, в том числе ещё не выпущенные изменения. Ссылка не меняется.

`https://yummyanime.github.io/yummy-lampa-plugin/dist/index.js`

Проверенные версии помечаются тегом `vX.Y.Z`. Выпуск и откат:

```
node scripts/release.js
node scripts/release.js --promote 0.41.38
```

Экран `YummyAnime → Статус` показывает историю YummyStatus за 3 часа, день, неделю или месяц. Снимок мониторинга обновляется GitHub Actions каждые пять минут.

## API

Используются методы:

- `GET /anime` — каталог и фильтры;
- `GET /anime/genres` — жанры.
- `GET /anime/{id}/videos` — доступные озвучки, серии и iframe-плееры.

Поиск передаётся параметром `q`. Выбранный публичный ключ приложения передаётся в заголовке `X-Application`. После входа личный Bearer-токен пользователя отправляется отдельно в авторизованных запросах. Расширение не создаёт приложения YummyAnime автоматически.

## Структура

- `index.js` — точка входа;
- `src/api.js` — клиент Yani API;
- `src/catalog.js` — модуль каталога;
- `src/config.js` — конфигурация;
- `src/i18n.js` — русская, английская и украинская локализация;
- `src/ui-detail.js` — подробная карточка тайтла, переводы, рейтинги, списки, рекомендации и комментарии;
- `src/ui.js` — интеграция с Lampa;
- `src/stream-resolver.js` — прямые потоки Kodik, CVH, Aksor, Sibnet, Rutube и VK;
- `src/yani-resolver.js` — клиент собственного сервиса-резолвера из `server/`;
- `src/lampac-resolver.js` — необязательный адаптер собственного Lampac-сервера для Alloha;
- `server/` — сервис, превращающий страницу плеера Alloha в обычный HLS-поток;
- `style.css` — стили.

## Воспроизведение и Alloha

Прямые ссылки HLS/DASH/MP4/WebM можно открывать во внутреннем плеере Lampa или во внешнем Android-плеере. Способ выбирается в `Настройки → YummyAnime → Способ просмотра`.

Alloha прямой поток не отдаёт: страница плеера не работает вне iframe, манифест требует заголовков `authorizations` и `accepts-controls`, причём второй обновляется по WebSocket каждые пару минут, а токен в пути `master.m3u8` одноразовый. Браузер такие заголовки к кросс-доменному запросу добавить не может, поэтому расширение само эту задачу не решает и обращается к внешнему сервису.

Источники прямого потока пробуются по очереди:

1. **Сервер резолвера** (`Настройки → YummyAnime → Сервер резолвера YummyAnime`) — сервис из папки [`server/`](../server/README.md), который держит живую сессию Alloha в headless-браузере и проксирует манифест с актуальными заголовками. Даёт точное совпадение по серии и озвучке.
2. **Сервер Lampac** (`Настройки → YummyAnime → Сервер Lampac`) — ищет тайтл заново по внешним идентификаторам, поэтому для аниме срабатывает не всегда.
3. **Встроенный плеер сайта** — переключатель `Alloha: встроенный плеер сайта`, выключен по умолчанию. Открывает оригинальный плеер Alloha внутри Lampa: работает без всякой инфраструктуры, но без таймлайна Lampa и без внешнего плеера.

Если ничего не настроено, при выборе Alloha показывается предупреждение, а воспроизведение блокируется. Пустое значение адреса полностью отключает соответствующий адаптер. Расширение не содержит ключи Alloha или Lampac.

Интеграция с частным приложением YummyTV выключена по умолчанию и включается отдельным переключателем в блоке источников воспроизведения.

## Реализовано

- подробная карточка аниме;
- рекомендации и трейлеры;
- избранное и пользовательские списки;
- обновление Bearer-токена через `/profile/token`;
- комментарии только для просмотра.

В настройках Lampa появится раздел `YummyAnime` с проверкой доступности ресурса и API.

GET-запросы к YummyAnime кэшируются локально на короткое время и могут быть показаны при временной недоступности API.

GitHub Actions автоматически проверяет синтаксис JavaScript при каждом push и pull request.

Авторизованный токен автоматически обновляется через `GET /profile/token`.

Подробная карточка использует данные Yani, а трейлеры и рекомендации подключаются через `/anime/{id}/trailers` и `/anime/{id}/recommendations`.
