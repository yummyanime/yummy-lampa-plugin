# Alloha resolver для Lampa

Этот небольшой сервер помогает Lampa воспроизводить видео из Alloha. Он
открывает веб-плеер в фоновом Chromium и передаёт в Lampa обычный HLS-поток.
После этого видео можно смотреть во внутреннем или внешнем плеере.

## Какой вариант выбрать

- **Только дома:** запустите сервер обычным способом и укажите его локальный
  адрес в Lampa.
- **Доступ через Интернет:** используйте защищённый вариант с Docker и HTTPS.
  Не открывайте обычный порт `8790` в Интернет.

## Запуск в домашней сети

```bash
cd server
npm install
npm start
```

При первой установке Playwright скачает Chromium — около 150 МБ.

Откройте настройки YummyAnime в Lampa и укажите адрес сервера:

```text
http://192.168.1.10:8790
```

Замените `192.168.1.10` на локальный IP компьютера или сервера. Устройство с
Lampa должно находиться в той же сети.

## Почему расширению нужен отдельный сервер

Alloha отдаёт не готовую ссылку на видео, а защищённый веб-плеер. Для загрузки
потока нужны служебные заголовки и регулярно обновляемый токен. Обычная
веб-версия Lampa не может получить их напрямую из-за ограничений браузера.

Resolver держит страницу Alloha открытой в фоне, получает актуальные данные и
передаёт поток в понятном для медиаплеера виде. Похожий подход используется в
Android-приложении YummyTV.

## Настройки сервера

Менять эти параметры необязательно. Значения по умолчанию подходят для обычного
локального запуска.

| Переменная | По умолчанию | Для чего нужна |
|---|---|---|
| `YANI_RESOLVER_PORT` | `8790` | Порт сервера |
| `YANI_RESOLVER_HOST` | `0.0.0.0` | Сетевой интерфейс |
| `YANI_RESOLVER_IDLE_MS` | `300000` | Когда закрывать неиспользуемую сессию |
| `YANI_RESOLVER_HEADLESS` | `true` | Укажите `false`, чтобы видеть окно Chromium при отладке |
| `YANI_RESOLVER_VERBOSE` | `false` | Подробные сообщения в журнале |
| `YANI_RESOLVER_REFRESH_WAIT_MS` | `12000` | Сколько ждать обновления сессии Alloha |
| `YANI_RESOLVER_PUBLIC_BASE` | — | Внешний HTTPS-адрес защищённого сервера |
| `YANI_RESOLVER_SANDBOX` | `false` | Chromium sandbox; Docker-вариант включает его сам |

## Доступ через Интернет

Для удалённого доступа используйте готовую конфигурацию Docker Compose. Она
оставляет resolver внутри Docker-сети и открывает только HTTPS-вход с длинным
секретным адресом.

Пошаговая инструкция: [deploy/README.md](deploy/README.md).

## API

Этот раздел нужен только для разработки и диагностики.

- `GET /health` — состояние сервера и число активных сессий.
- `GET /resolve?url=<iframe-url>` — получить HLS-ссылку и доступные качества.
- `GET /hls/<id>/q/<label>/master.m3u8` — поток выбранного качества.
- `GET /hls/<id>/master.m3u8` — поток текущей сессии.
- `GET /hls/<id>/p?u=<base64url>&s=<signature>` — сегмент или вложенный плейлист.
- `GET /release?session=<id>` — закрыть сессию раньше времени.

Ссылки на сегменты подписываются временным ключом. После перезапуска resolver
старые ссылки перестают работать, а Lampa получает новые при следующем запуске
серии.

## Ограничения

- Каждая активная серия использует отдельную вкладку Chromium и расходует
  память.
- Устройства, одновременно открывшие одну и ту же серию, используют общую
  сессию.
- Доступность Alloha зависит от сети и региона, где запущен сервер.
